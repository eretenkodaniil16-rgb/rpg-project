# Краткий игровой дизайн

## Формат первой версии

Сюжетная 2D-RPG с исследованием небольших локаций, диалоговыми выборами, проверками характеристик, квестами и пошаговыми столкновениями. Первая версия должна быть короткой законченной главой, а не незавершённым большим миром.

## Первый технический прототип

Прототип проверяет полный минимальный цикл:

1. Запуск главного меню.
2. Создание новой игры или загрузка сохранения.
3. Перемещение героя по тестовой комнате.
4. Взаимодействие с NPC.
5. Выбор реплики в диалоге.
6. Изменение сюжетного флага.
7. Сохранение результата.

## Текущие ограничения

- Используется временная геометрическая графика.
- Боевой системы и инвентаря пока нет.
- Мобильные экранные кнопки будут добавлены после проверки базового прототипа на Windows.
- Текст и сеттинг тестовой сцены не считаются окончательным сюжетом.
