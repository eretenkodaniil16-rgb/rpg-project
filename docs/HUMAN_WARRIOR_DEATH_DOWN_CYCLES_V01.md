# human_warrior_m01 — weapon-agnostic death down cycles v01

## Цель

Расширить три утверждённых набора `death_*_base_down_keyposes_v01` до
полноценных анимаций направления `down`, не меняя принятые ключевые позы,
внешность персонажа и физические стороны экипировки.

Этап остаётся изолированным Blender review-пайплайном. Runtime, игровые
атласы, случайный выбор варианта и остальные направления не подключаются.

## Общий тайминг

Каждый вариант содержит 8 кадров при 10 FPS, то есть 0,8 секунды до перехода
в постоянный corpse-state:

1. `guard`;
2. `stagger` — новый промежуточный кадр;
3. `balance_break`;
4. `knee_drop`;
5. `fall_acceleration` — новый промежуточный кадр;
6. `ground_impact`;
7. `final`;
8. `corpse_hold` — побитно одинаковое удержание финальной позы.

Анимации `non-loop`. После завершения runtime в будущем должен оставить кадр
`corpse_hold`, а не возвращать персонажа в idle.

## Сохранение утверждённых key poses

Пять исходных поз переносятся без изменения числовых трансформаций:

| Исходный key pose | Кадр полного цикла |
|---|---:|
| `f01 guard` | `f01` |
| `f02 balance_break` | `f03` |
| `f03 knee_drop` | `f04` |
| `f04 ground_impact` | `f06` |
| `f05 final` | `f07`, `f08` |

Интерполяция используется только в `f02` и `f05`. Она выполняется над
существующими параметрами рига и не добавляет root translation, mirroring,
negative scale, новую геометрию или новые материалы.

## Варианты

### death_01_base

Тяжёлое падение вправо-назад. Источник
`death_01_base_down_keyposes_v01_pass02_approved` сохраняется без изменения.

### death_02_base

Фронтальное падение в противоположную сторону. Вариант остаётся отдельным
движением, а не зеркальной копией `death_01`.

### death_03_base

Разделение тела в области пояса начинается на `f06 ground_impact`:

- `f06` использует утверждённые позу, смещение и pixel seam исходного `f04`;
- `f07` использует утверждённый финальный split-state исходного `f05`;
- `f08` удерживает тот же финальный split-state без дрожания;
- туловище с головой и руками остаётся одной крупной массой;
- таз и обе ноги остаются второй крупной массой;
- оружейный слой скрыт на всех кадрах.

Renderer повторно использует проверенные cut-cap и детерминированный RGBA8
pixel seam из этапа key poses. Новая геометрия расчленения не создаётся.

## Технический контракт

- 3 варианта × 8 кадров = 24 PNG;
- `96×96 RGBA`, binary alpha;
- baseline `y=91`;
- `down`, без зеркалирования;
- 10 FPS, 0,8 секунды, `non-loop`;
- `corpse_hold` совпадает с `final` по RGBA-пикселям;
- appearance v03, head v22, proxy v25;
- weapon-agnostic: оружие полностью скрыто;
- финальная corpse-поза постоянна;
- runtime connected = false.

## Следующий этап после ручного утверждения

1. зафиксировать три `base_down` цикла как художественный источник;
2. перенести их на `left/right/up` реальным поворотом рига без mirroring;
3. после directional-проверки собрать approved-атласы отдельным integration PR;
4. подключить selector без немедленного повтора с fallback `death_01_base`;
5. закрепить приоритет `death > hit > attack/movement`.
