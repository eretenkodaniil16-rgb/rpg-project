# Main Theme v01 — «Тема странника»

## Статус

Композиция `main_theme_v01` утверждена пользователем 5 августа 2026 года. Мелодия, гармония, темп, размер, форма и общий характер зафиксированы и не должны изменяться без отдельного творческого решения.

Текущий ресурс — **интегрированный master candidate**. Он включён для главного меню и создания персонажа. Статус `release approved` будет присвоен после проверки в Godot на Windows и физическом Android-устройстве.

## Зафиксированный композиционный стандарт

- темп: `76 BPM`;
- размер: `6/8`;
- длительность: `32 такта`, `75,789 с`;
- центр: `D`;
- ладовая основа: минор с дорийской и фригийской окраской;
- главный лейтмотив: `D4 — A3 — C4 — Eb4 — D4`;
- характер: сдержанное тёмное фэнтези, дальнее путешествие, холод и скрытая угроза;
- постоянного оркестрового максимума нет.

## Форма

| Такты | Раздел | Назначение |
| --- | --- | --- |
| 1–8 | Intro A | Разреженное вступление и первое появление мотива |
| 9–16 | Variation A | Хор и расширенный ответ струнных |
| 17–24 | Middle B | Тревожная средняя часть с фригийской окраской |
| 25–32 | Reprise | Возвращение мотива и разрешение для повтора |

## Чистовой кандидат

`tools/audio/render_main_theme_v01_master.py` создаёт рендер из утверждённой партитуры без внешних записей, sample pack, импортированного MIDI или сторонней генерации. В сравнении с прототипом добавлены:

- коррекция низких и резких высоких частот;
- более широкое, но совместимое с mono стереополе;
- дополнительные ранние отражения и затухающее пространство;
- мягкая компрессия и безопасный запас по пику;
- отдельный Ogg Vorbis экспорт для Android.

В runtime `MusicManager` включает нативный `AudioStreamOggVorbis.loop`, поэтому трек не перезапускается вручную между циклами.

## Игровой ресурс

```text
assets/audio/music/
├── source/
│   ├── main_theme_v01_score.json
│   ├── main_theme_v01_provenance.json
│   └── main_theme_v01_master_manifest.json
└── exports/
    └── main_theme_v01_master.ogg
```

Параметры игрового Ogg:

- Vorbis stereo;
- 48 кГц;
- длительность `75,789 с`;
- размер менее `2,5 МБ`;
- нативная петля;
- громкость трека в каталоге `-5 dB`, дополнительно применяется пользовательская громкость шины `Music`.

## Интеграция

`data/audio/music_catalog.json` связывает `main_theme` с:

- `main_menu`;
- `character_creation`.

`MusicManager` автоматически распознаёт `res://scenes/menus/main_menu.tscn`, выполняет плавное появление за `1,5 с` и не создаёт отдельной зависимости сцены меню от конкретного аудиофайла.

## Воспроизводимость

Прототип:

```bash
python tools/audio/generate_main_theme_v01.py \
  --score assets/audio/music/source/main_theme_v01_score.json \
  --output build/audio/main_theme_v01
```

Master candidate:

```bash
python tools/audio/render_main_theme_v01_master.py \
  --score assets/audio/music/source/main_theme_v01_score.json \
  --output build/audio/main_theme_v01_master
```

## Обязательная проверка перед release approval

1. запуск и плавное появление в главном меню;
2. отсутствие щелчка, паузы и заметного провала после полного цикла;
3. отсутствие повторного старта при переходе в создание персонажа;
4. корректное восстановление после сворачивания Android-приложения;
5. баланс на динамике телефона и в наушниках;
6. отсутствие перегруза относительно UI и будущих звуков окружения;
7. размер APK и отсутствие ошибок импорта Godot.
