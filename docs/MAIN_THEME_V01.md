# Main Theme v01 — «Тема странника»

## Статус

`main_theme_v01` — оригинальный музыкальный прототип для главного меню «Хроник странника».

Это **не утверждённый финальный игровой ресурс**. Каталог `MusicManager` остаётся отключённым до прослушивания пользователем и проверки петли в Godot на Windows и Android.

## Композиционный стандарт

- темп: `76 BPM`;
- размер: `6/8`;
- длительность: `32 такта`, около `75,79 с`;
- центр: `D`;
- ладовая основа: минор с дорийской и фригийской окраской;
- главный лейтмотив: `D4 — A3 — C4 — Eb4 — D4`;
- характер: сдержанное тёмное фэнтези, дальнее путешествие, холод и скрытая угроза;
- постоянного оркестрового максимума нет.

## Форма

| Такты | Раздел | Назначение |
| --- | --- | --- |
| 1–8 | Intro A | Разреженное вступление и первое появление мотива |
| 9–16 | Variation A | Хор и расширенный ответ струнных |
| 17–24 | Middle B | Тревожная средняя часть с фригийской окраской |
| 25–32 | Reprise | Возвращение мотива и разрешение для повтора |

## Инструментальная модель прототипа

- низкие смычковые;
- тёмные щипковые струны;
- деревянная флейта;
- низкий хор без текста;
- дальние металлические колокола;
- рамочный барабан;
- воздушная комнатная текстура.

Текущий WAV/Ogg создаётся собственным детерминированным синтезатором без внешних записей и sample pack. Это обеспечивает проверяемое происхождение, но не заменяет будущий чистовой рендер на качественных виртуальных инструментах.

## Исходники

- `assets/audio/music/source/main_theme_v01_score.json` — композиционные данные и утверждаемые параметры;
- `tools/audio/generate_main_theme_v01.py` — генератор MIDI, WAV и Ogg;
- `tests/test_main_theme_v01.py` — проверка структуры и технического результата.

Команда генерации:

```bash
python tools/audio/generate_main_theme_v01.py \
  --score assets/audio/music/source/main_theme_v01_score.json \
  --output build/audio/main_theme_v01
```

Генератор создаёт:

```text
build/audio/main_theme_v01/
├── main_theme_v01.mid
├── main_theme_v01_mockup.wav
├── main_theme_v01.ogg
└── main_theme_v01_manifest.json
```

## Критерии утверждения

Перед переводом в `approved` необходимо проверить:

1. узнаваемость пятинотного мотива;
2. соответствие атмосфере главного меню;
3. отсутствие утомляющей плотности при повторе;
4. отсутствие щелчка и заметного провала на границе петли;
5. баланс на динамике телефона;
6. корректное восстановление после сворачивания Android-приложения;
7. отсутствие сходства, требующего переработки, с известной защищённой композицией.

После утверждения потребуется отдельный ресурсный коммит с мастер-WAV и игровым Ogg, обновление `music_catalog.json` и runtime-проверка в Godot. Текущий PR этого намеренно не делает.
