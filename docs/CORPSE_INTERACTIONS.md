# Тела, добыча и перетаскивание

## Назначение

Система превращает побеждённого NPC в сохраняемый объект мира. Она использует существующие `GameState.inventory`, каталог действий и сохранение сюжетных флагов; отдельный инвентарь для тел не создаётся.

## Состояния

- `alive` — NPC участвует в обычных системах;
- `unconscious` — NPC без сознания, его можно осмотреть и перетащить, но нельзя обыскивать;
- `dead` — тело можно осмотреть, обыскать и перетащить.

Исход задаётся для стабильного `actor_id` в `data/world/corpse_loot_profiles.json`.

## Сохранение

Реестр хранится в `story_flags.corpse_registry_v1`. Запись содержит:

- `corpse_id`;
- `actor_id`;
- `body_state`;
- `remaining_loot`;
- `drag_weight`;
- последнее сохранённое положение.

Старые сохранения безопасны: отсутствие реестра означает, что все NPC загружаются живыми.

## Добыча

Передача предмета выполняется транзакционно:

1. проверяется состояние `dead`;
2. проверяется запись предмета на теле;
3. проверяется определение предмета и свободная вместимость существующего инвентаря;
4. предмет добавляется через `GameState.add_item(..., false)`;
5. только после успешного добавления уменьшается количество на теле;
6. реестр и инвентарь сохраняются одной операцией.

Нестакаемый предмет не исчезает с тела, если такой предмет уже находится в инвентаре.

## Перетаскивание

- доступно только вне пошагового боя;
- одновременно можно тащить одно тело;
- скорость исследования умножается на `0.58`;
- тело следует позади героя;
- положение сохраняется при отпускании, начале боя и выходе в меню.

## Контекстные действия

Для выбранного тела каталог `ДЕЙСТВИЯ` показывает:

- `ОСМОТРЕТЬ ТЕЛО`;
- отдельные действия снятия предметов;
- `ЗАБРАТЬ ВСЁ`;
- `ТАЩИТЬ ТЕЛО` / `ОТПУСТИТЬ ТЕЛО`;
- `СНЯТЬ ВЫБОР`.

В бою тела не считаются доступными боевыми целями.

## Граница этапа

Реакция NPC на обнаруженное тело, мораль отряда, маги и выбор тактических заклинаний реализуются в отдельном stacked PR поверх этого контракта.
