# Внутриигровое меню паузы v01

## Назначение

Этап добавляет единое внутриигровое меню паузы для Windows и Android и переиспользует панель настроек из PR #87 без копирования аудиологики или хранения настроек.

## Зависимость

Ветка `feat/in-game-pause-menu-v01` создана поверх `feat/main-menu-settings-v01`. До объединения PR #87 этот этап должен оставаться stacked PR с базой `feat/main-menu-settings-v01`.

## Архитектура

`InGamePauseController` установлен отдельным дочерним узлом в `game.tscn`. Текущий корневой runtime Сторожевого поста не заменён и не расширен новым слоем наследования.

Контроллер:

- создаёт `InGamePauseMenu` внутри `Interface`;
- обрабатывает `ui_cancel` до старого прямого выхода из игры;
- ставит `SceneTree` на паузу только когда нет блокирующего интерфейса;
- владеет только той паузой, которую установил сам;
- снимает свою паузу перед выходом из сцены;
- очищает мобильный ввод перед остановкой игры;
- вызывает существующий `return_to_menu()`, который сохраняет игру;
- сохраняет fallback на прямую смену сцены, если старый runtime-контракт отсутствует.

## Интерфейс

Меню содержит:

- `ПРОДОЛЖИТЬ`;
- `НАСТРОЙКИ`;
- `В ГЛАВНОЕ МЕНЮ`.

Все основные кнопки имеют высоту 64 px. Вложенная панель настроек — существующая `res://scenes/ui/main_menu_settings_panel.tscn`.

## Управление

- кнопка `МЕНЮ` на мобильном HUD открывает паузу;
- `Esc` или Android Back открывает паузу в обычной игре;
- повторный `Esc`/Back продолжает игру;
- при открытых настройках Back сначала закрывает настройки, не снимая паузу;
- при блокирующем диалоге или другом существующем оверлее пауза не накладывается поверх него.

## Сохранения

Контроллер не реализует сохранение самостоятельно. Пункт `В ГЛАВНОЕ МЕНЮ` сначала снимает паузу, затем вызывает существующий `return_to_menu()`, поэтому используется текущий контракт `GameState.save_game()`.

## Проверки

`tests/test_in_game_pause_menu.py` фиксирует статические контракты сцены, контроллера и мобильной кнопки.

`tests/smoke_in_game_pause_menu.gd` проверяет:

- установку контроллера в реальную игровую сцену;
- остановку и возобновление `SceneTree`;
- размеры touch targets;
- сброс активного вектора джойстика;
- открытие общей панели настроек;
- закрытие настроек без снятия паузы;
- мобильную кнопку `МЕНЮ`;
- `ui_cancel`/Android Back;
- отсутствие зависшей паузы после закрытия.

## Ручная проверка

1. Открыть меню во время исследования мира.
2. Открыть его в бою на ходу игрока.
3. Удерживая джойстик, нажать `МЕНЮ`, затем продолжить игру — герой не должен двигаться самостоятельно.
4. Изменить громкость, закрыть настройки и убедиться, что бой/мир остаётся на паузе.
5. Проверить системную кнопку Back на Android.
6. Выбрать `В ГЛАВНОЕ МЕНЮ`, затем загрузить сохранение и проверить последнюю сохранённую позицию.
