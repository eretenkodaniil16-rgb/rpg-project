# Контейнеры и добыча

## Назначение

Система замыкает приключенческий цикл `исследование → источник добычи → инвентарь → сохранение` и расширяет существующие механики без создания второго инвентаря.

## Источники

Поддерживаются два типа источников:

- контейнеры мира с постоянным `container_id`;
- мёртвые NPC, уже обслуживаемые `CorpseInteractionSystem`.

Оба источника открываются через одну мобильную `LootContainerPanel`. Для игрока предметы всегда подписываются как `ПОДОБРАТЬ: <русское название>`. Системный `item_id` используется только в данных и коде.

## Состояние контейнера

Каждая запись содержит:

- `container_id`;
- `container_type`;
- русское `label`;
- позицию;
- `is_open`;
- `is_locked` и `lock_id`;
- `is_discovered`;
- массив оставшихся предметов.

Контейнеры мира сериализуются в `world_snapshot.environment.loot_containers`. Старый снимок без этого раздела получает начальные записи из `data/world/loot_containers.json`.

## Перенос предметов

`LootContainerSystem` выполняет синхронный перенос:

1. проверяет существование источника и предмета;
2. проверяет блокировку и открытое состояние;
3. рассчитывает доступную вместимость существующего инвентаря;
4. добавляет точное количество;
5. только после успешного добавления уменьшает запись источника;
6. при частичной вместимости оставляет остаток в контейнере.

Повторное нажатие не может получить уже удалённый стек, потому что запись меняется до следующего события UI.

## Бой

В пошаговом бою:

- контейнер или тело можно открыть только на ходу игрока;
- один подобранный стек расходует дополнительное действие;
- `ЗАБРАТЬ ВСЁ` отключено;
- после подбора панель закрывается и интерфейс хода обновляется.

Вне боя массовый подбор разрешён. Предметы, которые не помещаются, остаются в источнике.

## Тестовые источники

- `guard_post_supply_chest_01` — стрелы, дротики и монеты;
- `guard_post_abandoned_satchel_01` — набор лекаря, пергамент и воровские инструменты.

Это проверочный контент. Художественные ресурсы контейнеров пока заменены программным fallback-представлением.
