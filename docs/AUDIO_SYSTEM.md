# Музыкальная и аудиосистема

## Статус этапа

Реализован фундамент музыки для Godot 4.7.1 Standard. Система зарегистрирована как autoload `MusicManager`, создаёт аудиошины, хранит пользовательскую громкость и выбирает музыкальный контекст для меню, создания героя, исследования и пошагового боя.

Оригинальные композиции на этом этапе не добавлены. Все записи каталога намеренно отключены, поэтому текущая сборка остаётся бесшумной и не падает при отсутствии аудиофайлов.

## Архитектура

`MusicManager` содержит два непозиционных `AudioStreamPlayer` для кроссфейда и отдельный проигрыватель коротких stinger-сигналов. Игровые сцены используют стабильные идентификаторы, а не пути к файлам:

```gdscript
MusicManager.play_context(&"world_exploration")
MusicManager.play_stinger(&"quest_completed")
```

Основной каталог расположен в `res://data/audio/music_catalog.json` и содержит три независимых раздела:

- `contexts` — логическое состояние игры и связанный `track_id`;
- `tracks` — длинные фоновые композиции;
- `stingers` — короткие сигналы поверх текущей музыки.

Неизвестный идентификатор, отключённая запись, пустой путь, отсутствующий файл или ресурс неверного типа безопасно отклоняются. Сцена при этом продолжает работать.

## Автоматические контексты

Раз в 0,25 секунды лёгкий `Timer` проверяет только текущую корневую сцену и публичный метод `is_turn_based_combat_active()`:

| Состояние | Контекст |
| --- | --- |
| Главное меню | `main_menu` |
| Создание героя | `character_creation` |
| Игровая сцена вне боя | `world_exploration` |
| Пошаговый бой | `combat_standard` |

Это четыре простых проверки в секунду, без обновления UI и без загрузки ресурсов каждый кадр. Для кат-сцен, сюжетной тревоги и особых боёв предусмотрен удерживаемый override:

```gdscript
MusicManager.set_context_override(&"combat_climax")
MusicManager.clear_context_override()
```

## Аудиошины и настройки

При запуске гарантируется наличие шин:

- `Master`;
- `Music`;
- `Ambience`;
- `SFX`;
- `UI`;
- `Voice`.

Новые шины отправляются в `Master`. Громкость и mute-состояние сохраняются в `user://audio_settings.cfg`, то есть принадлежат приложению, а не конкретному слоту прохождения.

Публичный контракт для будущего экрана настроек:

```gdscript
MusicManager.set_bus_volume_linear(&"Music", 0.65)
MusicManager.set_bus_muted(&"Ambience", true)
```

## Подготовка музыки

Для Android рекомендуется экспортировать утверждённую музыку в Ogg Vorbis, stereo, 48 кГц, ориентировочно 96–128 Кбит/с. Цикл необходимо настроить в импорте Godot и проверить на физическом Android-устройстве.

Имена файлов должны быть версионными, например:

```text
main_theme_v01.ogg
exploration_calm_v01.ogg
combat_standard_v01.ogg
```

После добавления файла нужно заполнить `path`, установить `enabled: true` и сохранить прежний стабильный `music_id`. Сцены и код при замене композиции изменять не требуется.

## Предусмотренные идентификаторы

Длинные композиции:

- `main_theme`;
- `exploration_calm`;
- `exploration_tension`;
- `combat_standard`;
- `combat_climax`;
- `aftermath`.

Короткие сигналы:

- `combat_start`;
- `victory`;
- `quest_received`;
- `quest_completed`;
- `secret_discovered`.

## Проверки

`tests/test_music_system_foundation.py` проверяет схему каталога, стабильные идентификаторы, ссылки контекстов, допустимые шины, пути ресурсов, autoload и публичные контракты.

`tests/test_music_manager.gd` проверяет загрузку каталога, штатный fallback отключённых треков, неизвестные идентификаторы, создание шин и изменение громкости без записи тестового значения в пользовательские настройки.
