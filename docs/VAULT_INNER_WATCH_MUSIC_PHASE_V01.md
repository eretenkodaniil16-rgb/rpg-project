# Музыкальная кульминация внутреннего поста v01

## Назначение

Первое существующее сюжетное столкновение подключено к полному музыкальному циклу без HP-порогов и без привязки к локализованному тексту.

Столкновение: `vault_inner_watch_01`.
Источник фазы: `training_mage` — Рунный тактик.
Фаза: `rune_overload`.

## Последовательность

1. Начало боя: `combat_start_v01`.
2. Обычная фаза: `combat_standard_v01`.
3. Первый успешно совершённый уровневый боевой спелл Рунного тактика, начиная со второго раунда: событие `enemy_spell_committed`.
4. Профиль `climax` с trigger `dangerous_ability`: `combat_climax_v01`.
5. Победа: `aftermath_v01`, затем подходящая исследовательская тема.

## Почему событие считается надёжным

Сигнал испускается внутри `CombatAiTrainingMage.consume_combat_spell_slot()` только после успешного расходования ячейки. Этот метод вызывается после разрешения реакции на контрзаклинание. Поэтому:

- контрзаклинание не запускает кульминацию;
- отсутствие ячейки не запускает кульминацию;
- заклинание первого раунда не запускает кульминацию;
- действия стрелка и других NPC не запускают кульминацию;
- повторное событие при уже активном или восстановленном `climax` не перезапускает музыку;
- профиль `scripted` не перехватывается автоматикой.

## Сохранения

Новый формат сохранений не вводится. Активный `climax` уже хранится в `combat_music_profile_registry_v1`. После загрузки внутри боя профиль восстанавливается, а новое событие не создаёт повторного перехода.

## Расширение

Новые сюжетные бои добавляются через `data/audio/encounter_music_phase_events.json`. Runtime не содержит имени сцены, пути к конкретному узлу или проверки HP.
