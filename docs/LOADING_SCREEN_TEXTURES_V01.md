# Модульная полоса загрузки v03

## Статус

Этап фиксирует выбранную владельцем проекта полосу загрузки варианта 3 как отдельный переиспользуемый UI-набор. Статус — `runtime_candidate`, не `final`.

Механика загрузки и переходы между сценами не изменяются. Preview-сцена предназначена только для художественной и технической проверки ресурсов.

Утверждённый временный фон загрузочного экрана остаётся референсом следующего арт-этапа. Он намеренно не включён в этот PR, чтобы не смешивать подготовку крупного HQ-фона с модульной полосой и не повторять повреждение бинарных ресурсов.

## Модульная структура

Полоса не хранится одной нерастягиваемой картинкой. Она собирается из:

1. левого декоративного наконечника;
2. растягиваемого пустого трека;
3. растягиваемого синего заполнения;
4. перемещающегося блика;
5. правого декоративного наконечника;
6. фиксированного центрального рунного медальона.

Заполнение обрезается контейнером в соответствии со значением `0–100`. Наконечники сохраняют пропорции, центральная руна не растягивается.

## Godot

Переиспользуемый контрол:

```text
res://scenes/ui/loading_progress_bar_v03.tscn
```

Публичный метод:

```gdscript
set_progress(value)
```

Тестовая художественная сцена:

```text
res://scenes/menus/loading_screen_texture_preview.tscn
```

Preview использует нейтральную тёмно-синюю процедурную подложку и автоматически прокручивает прогресс от 0 до 100 за восемь секунд. При `accessibility/reduced_motion=true` устанавливается статическое значение 72%, а движение блика отключается.

## Ограничения

- текущий PR не содержит крупный фон загрузочного экрана;
- логотип и фон будут подготовлены отдельными HQ-слоями;
- контрол не подключён к реальной загрузке сцен;
- текущая полоса требует физической проверки на Android;
- линейная фильтрация применяется только к этому высокодетализированному UI, а не к gameplay pixel-art.

## Ручная проверка

1. Полоса остаётся чёткой при ширине от 640 до 1200 px.
2. Центральная руна не деформируется.
3. Левый и правый наконечники не обрезаются.
4. Заполнение корректно выглядит при 0%, 25%, 50%, 75% и 100%.
5. На Android нет заметных швов, размытия или падения частоты кадров.
6. Свечение не перекрывает надпись «Загрузка...».
