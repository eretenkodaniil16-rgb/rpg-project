# human_warrior_m01 — утверждённая библиотека gameplay-анимаций v01

## Назначение

Этот этап сохраняет в основной истории проекта только утверждённые игровые
ресурсы персонажа, без переноса сотен исторических диагностических pass-файлов.

В Git фиксируются восемь PNG-атласов:

1. idle;
2. walk;
3. combat idle one-hand;
4. combat idle two-hand;
5. walk one-hand;
6. walk two-hand;
7. attack_sword_01 one-hand;
8. attack_sword_01 two-hand overhead.

## Единый контракт

- ячейка: `96×96`;
- обычная высота персонажа: около `76–80 px`;
- baseline: `y=91`;
- камера: top-down 3/4, около 47°;
- строки: `down`, `left`, `right`, `up`;
- боковые направления не зеркальные;
- физические стороны наплечников, ножен, подсумка и оружия постоянны;
- alpha бинарный;
- масштабирование и повторная фильтрация при сборке атласов не применяются.

## Атаки

Одноручный и двуручный наборы содержат по 4 направления × 8 кадров.
Направления являются переносом одного мастер-движения с малыми локальными
корректировками читаемости, а не четырьмя независимо поставленными ударами.

Одноручный `up` сохранён без дополнительных локальных дельт после того, как
проверка показала ухудшение безопасного зазора клинка. Двуручный набор использует
утверждённый вертикальный overhead-удар сверху вниз.

## Интеграционная граница

Этот PR сохраняет художественные ресурсы и проверяемое происхождение. Он не
меняет логику боя, сохранения и управление. Подключение атак к
`HumanWarriorAnimationLibrary`, выбор анимации по действию и синхронизация
момента попадания выполняются следующим отдельным PR.
