# Exploration Calm v01 — «Тихая дорога»

## Статус

`exploration_calm_v01` — оригинальный интеграционный кандидат спокойной музыки исследования. Композиция подключается к контексту `world_exploration`, но не считается release-approved до ручного прослушивания в Godot на Windows и физическом Android-устройстве.

## Музыкальный контракт

- 72 BPM;
- размер 6/8;
- 36 тактов;
- длительность 90 секунд;
- тональный центр D;
- минор с дорийской окраской;
- исходный лейтмотив: `D4 — A3 — C4 — Eb4 — D4`;
- исследовательская вариация: `D4 — A3 — C4 — E4 — D4`.

Изменение `Eb → E` делает мотив светлее, но сохраняет его узнаваемый контур. Трек не повторяет главную тему буквально и не переходит в боевую кульминацию.

## Форма

| Такты | Раздел | Назначение |
| --- | --- | --- |
| 1–8 | Threshold | Первые шаги и разреженное появление мотива |
| 9–17 | Open Road | Более ясное движение и раскрытие дорийской окраски |
| 18–25 | Shadowed Path | Тихое напряжение без перехода в боевую музыку |
| 26–36 | Homeward Loop | Возвращение к D minor и подготовка повтора |

## Инструментарий

- тихие низкие смычковые;
- тёмный щипковый инструмент;
- деревянная флейта;
- редкий дальний колокол;
- воздушная комнатная текстура.

Хор, выраженный барабан и постоянный оркестровый максимум намеренно исключены.

## Рендер и происхождение

Генератор:

```text
res://tools/audio/generate_exploration_calm_v01.py
```

Партитура:

```text
res://assets/audio/music/source/exploration_calm_v01_score.json
```

Renderer использует музыкальные примитивы существующего оригинального пайплайна `main_theme_v01`. Внешние записи, sample pack, импортированный MIDI и сторонние композиции не используются.

Для зацикливания генерируются три последовательных цикла, после чего экспортируется средний. Благодаря этому хвосты струнных, флейты и реверберации продолжаются через границу без искусственного затухания в тишину.

## Runtime-интеграция

Каталог связывает:

```text
world_exploration → exploration_calm
```

Параметры:

- плавный переход: 2 секунды;
- шина: `Music`;
- громкость трека: `-7 dB`;
- нативный `AudioStreamOggVorbis.loop`;
- файл: `res://assets/audio/music/exports/exploration_calm_v01_master.ogg`.

Сцены не получают прямую зависимость от Ogg. Контекст выбирается существующим `MusicManager` для сцен с префиксом `res://scenes/game/`, когда пошаговый бой не активен.

## Воспроизводимость

```bash
python tools/audio/generate_exploration_calm_v01.py \
  --score assets/audio/music/source/exploration_calm_v01_score.json \
  --output build/audio/exploration_calm_v01
```

Выходы:

- `exploration_calm_v01.mid`;
- `exploration_calm_v01_master.wav`;
- `exploration_calm_v01_master.ogg`;
- `exploration_calm_v01_preview.mp3`;
- `exploration_calm_v01_master_manifest.json`.

## Проверка перед утверждением

1. Переход из главного меню в игру должен выполнить кроссфейд, а не резкий обрыв.
2. Полный 90-секундный цикл не должен иметь щелчка или паузы.
3. Загрузка сохранения в игровой сцене должна выбирать `world_exploration`.
4. Возврат в главное меню должен вернуть `main_theme` с плавным переходом.
5. Сворачивание и восстановление Android-приложения не должно запускать второй экземпляр трека.
6. Флейта должна читаться на динамике телефона, но не перекрывать UI и будущие звуки окружения.
7. Трек не должен восприниматься как начало боя или постоянная кульминация.
