# Planned Movement and Action Catalog

Версия: 0.12.0.

## Цели

Система разделяет намерение игрока и фактическое выполнение команды. Выбор клетки не перемещает персонажа немедленно: сначала строится маршрут, затем игрок подтверждает его отдельной командой.

## Единая модель препятствий

`CombatEnvironment` хранит для каждого препятствия:

- прямоугольную область;
- блокировку перемещения;
- блокировку линии видимости;
- бонус укрытия;
- возможность перепрыгивания.

На основе этих данных создаются физические `StaticBody2D`, вычисляются заблокированные клетки, строятся пути, принимаются решения ИИ и проверяется прыжок. Нельзя занимать клетку, частично перекрытую препятствием.

## Планирование пути

`PlannedMovementSystem` использует поиск по стоимости на восьми направлениях. Стоимость каждого шага учитывает:

- базовые 5 футов за клетку;
- труднопроходимую местность;
- ползание;
- перенос захваченной цели;
- оставшийся запас перемещения.

Маршрут не проходит через:

- препятствия;
- занятые клетки;
- границы поля;
- закрытые диагональные углы.

`MovementPlanOverlay` показывает клетки маршрута, линию, конечную клетку и итоговую стоимость.

## Подтверждение перемещения

После выбора маршрута доступны команды:

- `ПЕРЕМЕСТИТЬСЯ` — выполнить путь;
- `ОТМЕНИТЬ ПУТЬ` — удалить путь без затрат.

Каждый шаг повторно проверяется непосредственно перед выполнением. Если клетка стала занятой, герой получил состояние с нулевой скоростью или закончился запас перемещения, маршрут прерывается безопасно.

Атаки по возможности проверяются перед каждым шагом.

## Прыжок вне боя

Кнопка `ПРЫЖОК` доступна вне пошагового режима. Прыжок выполняется в направлении взгляда героя.

Условия:

- впереди должно находиться хотя бы одно препятствие с `jumpable = true`;
- можно пересечь не более двух клеток такого препятствия;
- клетка приземления должна быть свободной и проходимой;
- полные стены не перепрыгиваются;
- во время прыжка ввод временно блокируется.

## Каталог действий

`ActionCatalogUI` заменяет длинный ряд независимых кнопок. Каталог разделён на четыре категории.

### Перемещение

- подтвердить маршрут;
- отменить маршрут;
- лечь или встать.

### Действие

- атака;
- Рывок;
- Отход;
- Уклонение;
- захват;
- сбивание;
- толчок;
- освобождение из захвата;
- подготовка атаки;
- скрытность;
- классовые возможности с типом `action`;
- завершение хода.

### Дополнительное действие

Содержит классовые возможности с типом `bonus`. Использование обычного действия не блокирует дополнительное действие и наоборот.

### Реакция

Показывает состояние реакции и подготовленной атаки. Реакции пока срабатывают автоматически по заданным условиям.

## Расширение

Новые способности должны задавать `action_type` в структурированных данных:

```json
{
  "id": "example_ability",
  "name": "Пример",
  "action_type": "bonus"
}
```

Поддерживаемые значения:

- `action`;
- `bonus`.

Реакции и свободные действия будут добавлены отдельными типами после появления интерфейса ручного подтверждения реакций.
