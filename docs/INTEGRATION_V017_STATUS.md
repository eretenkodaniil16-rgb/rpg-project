# Интеграция gameplay v0.17.0

Эта ветка объединяет опубликованную игровую цепочку до draft PR №44 включительно и предназначена только для проверки перед переносом в `main`.

Включено:

- создание персонажа, расы, происхождения, классы и владения;
- пошаговый бой, перемещение, проверки, журнал и инвентарь;
- заклинания, ритуалы, ячейки, области и выбор целей;
- Counterspell и единый координатор реакций;
- явный выбор стартовой магии и источников заклинаний;
- Android workflows и мобильные smoke-тесты;
- защитный `.gitignore` из актуального `main`.

Не включено:

- локальный неопубликованный commit повышения уровня `751b839`;
- художественная ветка Blender Sprite Factory и draft PR №42;
- неутверждённые generated art assets.

Перед слиянием обязательны зелёные импорт Godot 4.7.1, профильные игровые тесты, Android debug export и Mobile Test APK.
