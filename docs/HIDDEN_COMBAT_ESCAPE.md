# Скрытое бегство из столкновения

## Назначение

Бегство не является мгновенной кнопкой выхода из боя. Герой должен разорвать линию обзора, успешно пройти проверку Скрытности против всех активных противников, подготовить бегство и достигнуть разрешённой зоны выхода без повторного обнаружения.

## Последовательность

1. Герой разрывает прямую линию обзора полным укрытием.
2. Действие `СКРЫТЬСЯ` расходует основное действие.
3. Выполняется Ловкость (Скрытность) против максимального пассивного Восприятия активных наблюдателей.
4. При успехе герой получает runtime-состояние `hidden`, а противники переходят в `searching` и запоминают последнюю известную позицию.
5. Действие `БЕГСТВО` включает подсветку разрешённых выходов. Оно не расходует дополнительное действие: это подтверждение намерения покинуть столкновение.
6. Герой перемещается к выходу. Любая клетка маршрута, видимая противнику, снимает скрытность и отменяет бегство.
7. Получение урона или применение способности также раскрывает позицию.
8. При достижении выхода скрытым и невидимым для всех активных противников столкновение получает состояние `abandoned` с причиной `player_escaped_hidden`.

## Поведение противников

Скрытый герой не является обычной целью атаки. В свой ход противник:

- идёт к последней известной позиции;
- восстанавливает визуальный контакт, если обходит укрытие;
- либо выполняет активную проверку Восприятия против сохранённого результата Скрытности;
- при успехе возвращает состояние `aware` и срывает бегство.

Состояния наблюдателя первой версии:

- `aware`;
- `searching`.

Они являются runtime-состояниями текущего боя. Итог бегства и тревога мира сохраняются через `EncounterSystem`.

## Data-driven настройки

Настройки находятся внутри определения столкновения:

```json
{
  "escape": {
    "policy": "hidden_boundary",
    "edges": ["west", "south"],
    "depth_cells": 1,
    "safe_anchor": [320.0, 360.0],
    "reason_id": "player_escaped_hidden",
    "alert_flag": "training_construct_alerted",
    "restore_participants": true
  }
}
```

Поддерживаемые политики:

- `hidden_boundary` — выход разрешён только после успешного скрытия;
- `forbidden` — пути отхода перекрыты.

Поддерживаемые края поля:

- `west`;
- `east`;
- `north`;
- `south`.

## Последствия успешного бегства

- XP и предметная награда победы не выдаются;
- потраченное здоровье и ресурсы героя сохраняются;
- временная скрытность очищается;
- противники восстанавливаются, когда `restore_participants` равно `true`;
- выставляется `alert_flag`, если он определён;
- герой переносится к `safe_anchor`;
- столкновение можно начать повторно, а `attempt_count` увеличивается.

## Архитектура

- `CombatEscapeSystem` владеет правилами, зонами и сопоставлением Скрытности с Восприятием;
- `game_hidden_escape_runtime.gd` координирует действия, движение, AI поиска и `EncounterSystem`;
- `EscapeZoneOverlay` только визуализирует выходы и не хранит игровой прогресс;
- состояние `abandoned` сохраняет существующий `GameState` под реестром столкновений.

## Границы первой версии

Не входят:

- освещение и тёмные зоны;
- шум и разные уровни слышимости;
- несколько групп преследования между сценами;
- сохранение точных позиций активного поиска;
- бегство группы спутников;
- специальные заклинания маскировки и невидимости;
- постоянные ранения отдельных врагов после ухода.
