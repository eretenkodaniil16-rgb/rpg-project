# Скрытое бегство и преследование

## Назначение

Бегство не завершается одним броском Скрытности и достижением края поля. Герой должен разорвать визуальный контакт, выбрать правдоподобный маршрут отхода и заставить каждого активного противника потерять его след.

Поддерживаются два маршрута:

- `hideout` — глубокое укромное место с повышенной сложностью обнаружения и отслеживания пути;
- `room_transition` — незаметный переход в соседнюю комнату с обязательным повторным скрытием внутри.

## Общая последовательность

1. Герой выходит из прямой линии обзора.
2. `СКРЫТЬСЯ` расходует основное действие и выполняет Ловкость (Скрытность) против пассивного Восприятия всех наблюдателей.
3. Противники запоминают последнюю позицию, где действительно видели героя, и переходят в `pursuing_last_seen`.
4. `БЕГСТВО` показывает доступные маршруты, но не завершает бой.
5. Скрытое перемещение оставляет последовательность следов по клеткам.
6. Враг сначала идёт к последней известной позиции, затем проверяет способность восстановить путь по следам.
7. После достижения конечного укрытия каждый противник должен провалить заданное число поисковых циклов.
8. Только после этого столкновение получает состояние `abandoned`.

## Укромное место

Маршрут `hideout` требует, чтобы герой находился в одной из `objective_cells` и успешно использовал `СКРЫТЬСЯ` именно там.

Укромное место задаёт:

- `concealment_bonus` — добавка к сложности окончательного поиска;
- `trace_dc_bonus` — добавка к сложности восстановления пути по следам;
- `required_search_sweeps` — сколько раз каждый противник должен потерять след;
- отдельный `safe_anchor` и `reason_id` при необходимости.

Выход из выбранного укрытия сбрасывает накопленный прогресс потери следа.

## Переход в другую комнату

Маршрут `room_transition` содержит:

- `transition_cells` — клетки дверного или коридорного перехода;
- `destination_cells` — логическая область соседней комнаты;
- `hide_cells` — места, где герой должен повторно использовать `СКРЫТЬСЯ`;
- `requires_rehide` — обязательность повторного скрытия;
- `blocks_cross_room_los` — разрыв прямой видимости между комнатами.

Пересечение перехода само по себе не завершает бой. Враги продолжают идти к последней известной позиции, могут найти оставленные клетки следа и постепенно приблизиться к новой комнате. Герой должен занять отмеченную точку, снова скрыться и пережить поиск.

## Состояния противника

- `aware` — герой находится под наблюдением;
- `pursuing_last_seen` — противник идёт к последнему месту визуального контакта;
- `tracking` — найден очередной участок следа;
- `searching` — след потерян, выполняется обыск области;
- `lost` — противник провалил требуемое число поисковых циклов.

Успешная проверка отслеживания переносит последнюю известную позицию на следующую клетку следа. Успешный окончательный поиск раскрывает героя даже без немедленного визуального контакта: противник замечает шум, отпечатки, смещённые предметы или другие признаки укрытия.

## Data-driven пример

```json
{
  "escape": {
    "policy": "pursuit_routes",
    "default_required_search_sweeps": 2,
    "reason_id": "player_escaped_after_pursuit",
    "alert_flag": "guards_alerted",
    "restore_participants": true,
    "routes": [
      {
        "id": "secret_niche",
        "type": "hideout",
        "objective_cells": [[11, 8]],
        "concealment_bonus": 6,
        "trace_dc_bonus": 4,
        "required_search_sweeps": 2
      },
      {
        "id": "service_room",
        "type": "room_transition",
        "transition_cells": [[1, 4], [1, 5]],
        "destination_cells": [[0, 3], [0, 4], [0, 5]],
        "hide_cells": [[0, 3], [0, 5]],
        "requires_rehide": true,
        "blocks_cross_room_los": true,
        "concealment_bonus": 3,
        "trace_dc_bonus": 2,
        "required_search_sweeps": 2
      }
    ]
  }
}
```

Политика `hidden_boundary` остаётся совместимой для старых данных, но новый контент должен использовать `pursuit_routes`. Политика `forbidden` полностью запрещает бегство.

## Последствия

- XP и добыча победы не выдаются;
- здоровье и потраченные ресурсы героя сохраняются;
- противники могут быть восстановлены по `restore_participants`;
- выставляется постоянный `alert_flag`;
- в журнал столкновения записываются маршрут, тип маршрута, результат Скрытности, число потерянных поисков и оставшиеся следы;
- повторная попытка увеличивает `attempt_count`.

## Архитектура

- `CombatEscapeSystem` разбирает маршруты, клетки комнат, бонусы укрытия и сложности поиска;
- `game_hidden_escape_runtime.gd` хранит только runtime-преследование: последнюю видимую позицию, следы, фазу маршрута и поисковый прогресс;
- `EscapeZoneOverlay` визуализирует укрытия, переходы и точки повторного скрытия разными цветами;
- итог `abandoned` сохраняется существующим `EncounterSystem`.

## Не входит в этот этап

- физическая симуляция звука и запаха;
- двери с отдельными состояниями открытия и запирания;
- переход противников между разными загруженными сценами;
- спутники и разделение группы;
- невидимость и магическое сокрытие;
- сохранение точных позиций незавершённого преследования при выходе из игры.
