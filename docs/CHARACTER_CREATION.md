# Создание персонажа

## Поток

1. Ввод имени длиной от 2 до 20 символов.
2. Шесть последовательных бросков `4d6` с отбрасыванием минимального кубика.
3. Свободное распределение шести результатов между характеристиками.
4. Выбор одного из 12 базовых классов.
5. Подтверждение и сохранение героя.

## Характеристики

- Сила (`strength`)
- Ловкость (`dexterity`)
- Телосложение (`constitution`)
- Интеллект (`intelligence`)
- Харизма (`charisma`)
- Мудрость (`wisdom`)

Модификатор рассчитывается как `floor((значение - 10) / 2)`.

## Начальное здоровье

`максимум кости здоровья класса + модификатор Телосложения`, минимум 1.

## Данные

Классы хранятся в `data/classes/classes.json`. Интерфейс не содержит жёстко заданного списка классов.
