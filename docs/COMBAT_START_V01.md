# combat_start_v01 — «Первый удар»

## Назначение

`combat_start_v01` — короткий одноразовый cue начала стандартного пошагового боя. Он накладывается поверх входящего `combat_standard_v01` и подчёркивает момент, когда угроза становится непосредственным столкновением.

## Музыкальный контракт

- 96 BPM, размер 6/8;
- длительность 3,125 секунды;
- первый низкий удар начинается без задержки;
- рубленая медная группа использует оригинальный фрагмент `D–Eb–A–D`;
- второй импульс подтверждает начало боевого ритма;
- короткий провал и финальный удар передают управление основному loop;
- последние 0,65 секунды освобождают спектр и затухают до цифровой тишины;
- внешние записи, сэмплы, импортированный MIDI и сторонние мелодии не используются.

## Runtime-контракт

`MusicCombatStartResolver` является узким переходным resolver, а не отдельной аудиосистемой. Воспроизведением по-прежнему управляет `MusicManager` через существующий `StingerPlayer`.

Cue запускается только при устойчивом переходе `is_turn_based_combat_active(): false → true` внутри одной игровой сцены. Он не запускается:

- при загрузке сцены или сохранения, если бой уже активен;
- на каждом ходе или раунде;
- после одиночного краткого ложного состояния `false`;
- вне `res://scenes/game/`;
- при отсутствии активного `combat_standard` контекста или ресурса stinger.

Для повторного боя resolver требует три последовательных небоевых опроса. Это защищает от дребезга состояния между фазами боя.

При подтверждённом начале боя resolver сначала просит `MusicThreatStateResolver` освободить tension override, затем запускает `combat_standard` с crossfade 0,75 секунды и поверх него `combat_start` на шине `Music` с громкостью −4,5 dB.

## Ручная проверка

1. Начать бой из спокойного исследования.
2. Начать бой из активной темы угрозы.
3. Убедиться, что cue слышен один раз и основной loop начинается под его хвостом.
4. Переключить несколько ходов и раундов — cue не должен повторяться.
5. Загрузить сохранение внутри боя — должен звучать только основной loop.
6. Завершить бой, подождать не менее 0,3 секунды и начать новый — cue должен снова сработать один раз.
7. Проверить динамик телефона и наушники: наложение не должно клиппировать или маскировать интерфейсные звуки.
