# Loading Screen Logo Blue V01

Холодный синий вариант логотипа утверждён владельцем как художественный референс.

- visual_id: `loading_screen_logo_blue_v01`;
- status: `reference_approved`;
- точный заголовок: `Хроники странника`;
- точный подзаголовок: `Башня, уходящая вниз`;
- spelling revision: `2`.

## Фактический статус реализации

Отдельная прозрачная текстура утверждённого логотипа пока не опубликована в репозитории. Ранее заявленный сборщик сегментов ссылался на отсутствующие файлы и удалён как незавершённый контракт.

До безопасной публикации чистового alpha-ресурса preview использует живые Godot-надписи. Это не заменяет утверждённый художественный референс, но гарантирует точную орфографию и работоспособный fallback.

## Исправление подзаголовка

В runtime-preview используется точный текст:

```text
Башня, уходящая вниз
```

Сгенерированный текст внутри изображения не является авторитетным источником. Статический и runtime-тесты проверяют точную строку и отклоняют известные ошибочные варианты.

## Что остаётся незавершённым

- чистая прозрачная текстура утверждённого синего логотипа;
- отдельная glow-маска;
- редкое мерцание именно графического логотипа;
- проверка финального alpha-ресурса в Android-сборке.

Текущий PR не подключает реальные переходы между сценами.
