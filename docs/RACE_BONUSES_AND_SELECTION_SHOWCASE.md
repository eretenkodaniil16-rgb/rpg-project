# Расовые бонусы и витринный выбор

Версия: 0.16.1

Документ описывает расовые бонусы, витринный выбор расы и класса, цикличные ленты, кнопки перехода и атаки без выбранной цели.

Расовые бонусы применяются один раз при создании персонажа. Итоговая характеристика ограничена значением 20.

На экранах расы и класса доступны кнопки предыдущего и следующего варианта. Переход выполняется по кругу. Горизонтальная лента также прокручивается циклично.

Без выбранной цели ближнее оружие атакует по направлению взгляда, а дальнее выпускает снаряд по направлению взгляда. Ручной выбор цели сохранён.

Название приложения и пользовательские подписи приведены к русскому языку. Отдельные проверки контролируют русские строки, цикличность выбора и свободные атаки.
