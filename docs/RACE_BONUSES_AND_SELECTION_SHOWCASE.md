# Витринный выбор вида и класса

Историческая версия: 0.16.1

> Стандарт расовых бонусов из версии 0.16.1 отменён переходом проекта на `ruleset_id = srd_5_2_1`. Вид персонажа больше не повышает характеристики. Увеличения характеристик предоставляет происхождение. Актуальный реестр: `docs/SRD_RULES_MATRIX.md`.

Документ сохраняет только решения интерфейса и свободных атак:

- на экранах вида и класса могут использоваться кнопки предыдущего и следующего варианта;
- переход между вариантами выполняется по кругу;
- горизонтальная лента может прокручиваться циклично;
- без выбранной цели ближнее оружие атакует по направлению взгляда;
- дальнее оружие выпускает снаряд по направлению взгляда;
- ручной выбор цели остаётся дополнительным способом точного наведения.

Старые поля `ability_bonuses` и `ability_bonus_description` удалены из данных видов. Старые сохранения не пересчитываются и получают служебное происхождение `legacy_origin`.
