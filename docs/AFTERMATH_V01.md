# Aftermath v01 — «После клинков»

`aftermath_v01` — одноразовая музыкальная фаза после победы в обычном пошаговом бою.

## Музыкальный контракт

- 72 BPM, 6/8, 9 тактов, 22,5 секунды;
- остаточный первый удар связывает cue с `combat_standard_v01`;
- ударные исчезают в первые секунды;
- низкие струны, редкие металлические отзвуки и фрагменты лейтмотива сохраняют напряжение;
- победной фанфары и замкнутого цикла нет;
- последние 100 мс тише -60 dBFS для безопасного возврата к исследованию;
- композиция оригинальная и процедурная, без внешних сэмплов и сторонних мелодий.

## Исходы боя

- `victory` — проиграть `aftermath_v01`, затем вернуть актуальный исследовательский контекст;
- `escape` — не проигрывать aftermath, немедленно восстановить угрозу/исследование;
- `defeat` — не проигрывать aftermath; музыкальное поражение будет отдельным этапом;
- `scripted_end` — музыка остаётся под управлением сценарной сцены.

`CombatOutcomeRegistry` хранит только одноразовые runtime-переопределения. Он не сериализуется: загрузка сохранения после боя устанавливает безопасный исследовательский baseline и не повторяет aftermath.

## Определение исхода

Resolver сначала потребляет явное значение из `CombatOutcomeRegistry`. При его отсутствии использует стабильный статус EncounterSystem:

- `resolved` / `rewarded` → `victory`;
- `abandoned` → `escape`;
- `failed` → `defeat`.

Для столкновений без `encounter_id` безопасным стандартом является `victory`, если герой не побеждён.
