# Главное меню: «Башня, уходящая вниз» v01

## Статус

`main_menu_tower_down_v01` — первый рабочий runtime-кандидат фирменного главного меню.
Владелец проекта утвердил фон варианта A и логотип варианта 2. Ресурс не считается финальным до проверки на Windows и Android.

## Архитектура

Существующая логика главного меню не заменена. Сохранены рабочие действия:

- продолжение через текущую панель слотов;
- новая игра через существующий конструктор персонажа;
- выход из приложения.

Новый визуальный слой состоит из:

- fallback-заливки, работающей без художественного ресурса;
- динамически загружаемого фона с встроенным утверждённым логотипом;
- процедурной атмосферной анимации;
- отдельной панели рабочих кнопок справа.

Фон намеренно загружается через `ResourceLoader.exists()`, а не является жёстким `ext_resource` сцены. Поэтому отсутствие WebP не ломает запуск меню.

## Атмосферная анимация

`MainMenuAtmosphere` рисует небольшой набор дешёвых эффектов:

- пульсацию магического круга;
- дыхание вертикального луча;
- несинхронное мерцание двух факелов;
- 11 магических искр;
- 17 частиц пыли.

Видео, полноэкранная покадровая анимация и тяжёлый постпроцесс не используются. При включённой настройке проекта `accessibility/reduced_motion` процесс анимации отключается, а меню остаётся статичным и полностью работоспособным.

## Мобильная компоновка

- базовый viewport проекта остаётся `1280×720`;
- фон использует `KEEP_ASPECT_COVERED`;
- изображение имеет целевое соотношение `1280×720`;
- меню закреплено в правой безопасной области;
- кнопки имеют высоту 54–60 px и сохраняют прежние сигналы.

## Что проверять вручную

1. Читаемость логотипа и кнопок на Windows.
2. Отсутствие обрезки логотипа на Android-экране.
3. Плавность анимации на физическом устройстве.
4. Независимое мерцание факелов без заметного синхронного цикла.
5. Открытие панели сохранений кнопкой «Продолжить».
6. Переход в создание персонажа кнопкой «Новая игра».
7. Отсутствие случайных нажатий при масштабировании кнопок.
8. Приемлемое энергопотребление и отсутствие падения частоты кадров.

## Следующий этап

После физического теста фон следует разделить на независимые чистые художественные слои: фон без текста, прозрачный логотип, круг, луч и факелы. Это позволит заменить процедурный MVP на более точную покадровую анимацию без изменения логики сцены.
