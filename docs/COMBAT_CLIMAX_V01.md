# Combat Climax v01

## Назначение

`combat_climax_v01` — кульминационная фаза пошагового боя. Она не запускается по
проценту здоровья. Переход разрешён только явным игровым событием:

- смена фазы босса;
- появление подкрепления;
- раскрытие опасной способности;
- сценарное изменение условий боя.

Текущие столкновения караульного поста остаются в профиле `standard`.

## Стабильные профили

- `standard` — `combat_standard_v01`;
- `climax` — `combat_climax_v01`;
- `scripted` — музыкальный resolver временно не принимает решений.

Профиль хранится в `CombatMusicProfileRegistry`. Для активного именованного
столкновения он также сохраняется в `GameState`, поэтому загрузка внутри
кульминационной фазы восстанавливает правильную музыку. После завершения боя
сохранённое состояние очищается.

Игровая сцена предоставляет:

```gdscript
request_combat_music_climax(&"boss_phase_02", "boss_character_id")
set_combat_music_profile(&"scripted", &"cutscene_takeover", "cutscene_id")
set_combat_music_profile(&"standard", &"phase_resolved", "boss_character_id")
```

## Музыкальный контракт

- 96 BPM, размер 6/8;
- 40 тактов, 75 секунд;
- тот же метр и темп, что у `combat_standard_v01`;
- самостоятельный мотив `D–Eb–F–A–D`;
- двойной струнный остинато;
- плотные военные барабаны и рамочные удары;
- расширенные медные сигналы;
- низкий синтетический хор;
- бесшовный цикл без победной каденции;
- внешние записи, сэмплы и импортированный MIDI не используются.

## Переходы

`standard → climax` использует crossfade 0,75 секунды. Повторный запрос той же
фазы идемпотентен. При победе resolver сначала передаёт управление
`MusicAftermathResolver`, поэтому `aftermath_v01` не сбрасывается. При бегстве
или поражении climax освобождается, после чего действует существующий контракт
исхода боя.

## Android

Master хранится как Ogg Vorbis, stereo, 48 кГц. Каталожная громкость `-5.5 dB`
компенсирует более плотный RMS кульминационной аранжировки и снижает риск
клиппинга на мобильном динамике.
