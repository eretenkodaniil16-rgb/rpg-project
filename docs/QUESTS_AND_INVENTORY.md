# Квесты и инвентарь

## Общая структура

Определения заданий хранятся в `data/quests/quests.json`, а предметов — в `data/items/items.json`.

Состояние прохождения и количество предметов хранятся в `GameState` и входят в версионированное сохранение.

## Состояние задания

Каждое задание имеет статус:

- `active` — выполняется;
- `completed` — завершено.

Активное задание хранит индекс текущего этапа. Этап завершается игровым событием, указанным в поле `event`.

Пример:

```json
{
  "id": "hit_training_dummy",
  "text": "Попасть по тренировочному чучелу",
  "event": "hit_training_dummy"
}
```

Игровая система сообщает событие через:

```gdscript
GameState.report_quest_event("hit_training_dummy")
```

## Награды

Награды задаются в данных квеста:

```json
{
  "item_id": "apprentice_token",
  "quantity": 1
}
```

При завершении последнего этапа награды автоматически добавляются в инвентарь.

## Инвентарь

Запись предмета содержит:

- стабильный `id`;
- отображаемое название;
- тип;
- описание;
- возможность складывания;
- максимальный размер стопки.

Основные методы:

```gdscript
GameState.add_item(item_id, quantity)
GameState.remove_item(item_id, quantity)
GameState.has_item(item_id, quantity)
GameState.get_item_count(item_id)
```

## Учебный квест

Квест `first_steps` начинается при создании новой игры:

1. Поговорить со Смотрителем.
2. Попасть по тренировочному чучелу.
3. Вернуться к Смотрителю.

Награда — `apprentice_token`. Разрушение тренировочного чучела дополнительно выдаёт `straw_scrap`.

## Ограничения версии 0.6.0

Пока отсутствуют:

- проваленные квесты;
- скрытые этапы;
- несколько одновременно отслеживаемых целей на экране;
- использование предметов;
- экипировка;
- вес и ограничение вместимости;
- выбрасывание и разделение стопок.
