# Loading Screen Composite V01

Стабильный идентификатор: `loading_screen_composite_v01`.

## Цель

Проверять композицию загрузочного интерфейса, точные надписи и модульную полосу `loading_bar_v03`, не подключая реальную механику переходов между сценами.

## Текущий состав

- детерминированный тёмно-синий procedural fallback;
- живая надпись `Хроники странника`;
- точный живой подзаголовок `Башня, уходящая вниз`;
- переиспользуемая полоса `loading_bar_v03`;
- preview-сцена `res://scenes/menus/loading_screen_composite_preview_v01.tscn`.

## Почему approved-фон временно отсутствует

Ранее загруженный `loading_screen_composite_v01.webp` оказался усечён до 15 КБ при передаче крупного бинарного файла и не являлся корректным игровым ресурсом. Файл удалён из runtime-дерева, а preview больше на него не ссылается.

Это обязательное техническое ограничение: повреждённый файл нельзя оставлять как fallback и нельзя считать утверждённым ресурсом. Согласованная иллюстрация башни остаётся художественным референсом и будет возвращена отдельным HQ-проходом через надёжный канал публикации бинарных файлов.

## Исправление орфографии

Обе надписи формируются Godot, а не считаются частью сгенерированного изображения:

```text
Хроники странника
Башня, уходящая вниз
```

Статический тест отклоняет известные ошибочные варианты. Runtime smoke-test проверяет точные строки после инстанцирования сцены.

## Технический статус

- `status=runtime_candidate`;
- `background_mode=procedural_fallback`;
- `connected_to_game_transitions=false`;
- игровая логика, реальные переходы и блокирующая загрузка не изменены.

## Ручная проверка

1. Проверить читаемость точного подзаголовка на Android.
2. Проверить масштаб заголовка на 16:9 и вытянутых экранах.
3. Проверить полосу при 0%, 50% и 100%.
4. Не оценивать procedural fallback как финальную иллюстрацию башни.
