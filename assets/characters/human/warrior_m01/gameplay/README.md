# Human Warrior M01 — gameplay visual

Первый утверждённый игровой персонаж проекта.

## Текущий пакет

- `human_warrior_m01_idle_down.png`
- `human_warrior_m01_idle_left.png`
- `human_warrior_m01_idle_right.png`
- `human_warrior_m01_idle_up.png`

Каждый кадр имеет размер `96×96`, прозрачный фон, единую базовую линию ступней и высоту персонажа около 80 пикселей.

## Визуальный стандарт

- полуреалистичный pixel-art тёмного фэнтези;
- бледная, но живая человеческая кожа;
- тёмные волнистые волосы;
- бордовый шарф и тканевые элементы;
- тёмная кожа, кольчуга и стальные пластины;
- фильтрация текстур в игре — `Nearest`;
- точка опоры — между ступнями.

## Область применения

На текущем этапе эти кадры используются только для комбинации `human + fighter`. Остальные расы и классы сохраняют прежний тестовый визуал до появления собственных пакетов.

## Анимационный контроллер

Игрок использует направления:

- `idle_down`, `idle_left`, `idle_right`, `idle_up`;
- `walk_down`, `walk_left`, `walk_right`, `walk_up`.

Пока полноценные кадры ходьбы отсутствуют, каждое состояние `walk_*` безопасно использует соответствующий `idle_*` как временный fallback. Это позволяет заранее проверить переходы состояний и не создавать отдельную временную систему.

`AnimatedSprite2D` размещён внутри общего узла `Body`. Сам тестовый полигон для человека-воина становится прозрачным, но сохраняет трансформации. Благодаря этому существующие выпады, прыжки и боевые жесты применяются к видимому спрайту без специальных зависимостей от конкретного персонажа.

## Следующий пакет

Первой полноценной анимацией остаётся `walk_down` из шести кадров с переносом веса, противофазой рук и ног и умеренным движением плеч. После утверждения одного цикла создаются остальные направления, затем `combat_idle`, `attack_sword_01`, `hit`, `death` и `interact`.
