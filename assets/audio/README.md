# Audio assets

Аудиоресурсы проекта разделяются по назначению и степени готовности:

- `music/source/` — исходные проекты и экспортные материалы композитора; в runtime не подключаются;
- `music/work/` — промежуточные версии;
- `music/approved/` — утверждённые мастер-файлы;
- `music/exports/` — оптимизированные Ogg Vorbis для Godot и Android;
- `ambience/` — фоновые звуки окружения;
- `sfx/` — игровые эффекты;
- `ui/` — звуки интерфейса;
- `stingers/` — короткие музыкальные сигналы.

Git не должен содержать неутверждённые тяжёлые исходники без отдельного решения. Runtime получает ресурсы только через стабильные идентификаторы из `res://data/audio/music_catalog.json`.

До утверждения оригинальных композиций записи каталога остаются `enabled: false`; отсутствие файла является штатным бесшумным fallback, а не ошибкой запуска.
