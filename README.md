# RPG Project

Сюжетная 2D-RPG на Godot с тестированием на Windows и основной целевой платформой Android.

## Зафиксированная версия движка

**Godot 4.7.1 Standard**, без .NET.

Использование другой версии допускается только после отдельной проверки совместимости и обновления этого файла.

## Текущее состояние

Первая техническая версия содержит:

- главное меню;
- новую игру и продолжение;
- тестовую комнату;
- перемещение персонажа;
- одного NPC;
- диалог из JSON с двумя вариантами ответа;
- сюжетные флаги;
- сохранение в `user://savegame.json`.

## Запуск

1. Установите Godot 4.7.1 Standard.
2. Клонируйте репозиторий или скачайте ZIP.
3. В Godot нажмите **Import**.
4. Выберите файл `project.godot`.
5. Откройте проект и нажмите `F6`/`F5` или кнопку запуска.

## Управление

- Стрелки — перемещение.
- `Enter` или `Пробел` — взаимодействие.
- `Esc` — закрыть диалог или вернуться в главное меню.

## Структура

- `scenes/` — сцены Godot.
- `scripts/` — GDScript.
- `data/` — структурированные игровые данные.
- `assets/` — будущие графика и звук.
- `docs/` — проектная документация.

## Порядок разработки

Изменения выполняются в отдельных Git-ветках и попадают в `main` через pull request после тестирования.
