# RPG Project

Сюжетная 2D-RPG на Godot с тестированием на Windows и основной целевой платформой Android.

## Зафиксированная версия движка

**Godot 4.7.1 Standard**, без .NET.

Использование другой версии допускается только после отдельной проверки совместимости и обновления этого файла.

## Текущее состояние

Техническая версия 0.3.0 содержит:

- главное меню;
- редактор персонажа;
- ввод имени;
- выбор одного из пяти цветов героя;
- генерацию шести характеристик методом `4d6` с отбрасыванием минимума;
- свободное распределение характеристик;
- выбор одного из 12 классов;
- расчёт модификаторов и начального здоровья;
- отображение выбранного имени и цвета на игровой сцене;
- тестовую комнату;
- перемещение стрелками на компьютере;
- экранные стрелки и управление перетаскиванием на Android;
- одного NPC;
- диалог из JSON с двумя вариантами ответа;
- сюжетные флаги;
- версионированное сохранение в `user://savegame.json`.

## Запуск

1. Установите Godot 4.7.1 Standard.
2. Клонируйте репозиторий или скачайте ZIP.
3. В Godot нажмите **Import**.
4. Выберите файл `project.godot`.
5. Откройте проект и нажмите `F6`/`F5` или кнопку запуска.

## Управление

- Стрелки — перемещение на компьютере.
- `Enter` или `Пробел` — взаимодействие на компьютере.
- `Esc` — закрыть диалог или вернуться в главное меню.
- На Android можно удерживать экранные стрелки или вести пальцем внутри левой зоны управления.
- Кнопка **ДЕЙСТВИЕ** отвечает за взаимодействие, кнопка **МЕНЮ** возвращает в главное меню.

## Структура

- `scenes/` — сцены Godot.
- `scripts/` — GDScript.
- `data/` — структурированные игровые данные.
- `assets/` — будущие графика и звук.
- `docs/` — проектная документация.

## Лицензирование правил

Используемые открытые механики и атрибуция описаны в `ATTRIBUTION.md`. Мир, сюжет и художественные элементы проекта должны оставаться оригинальными.

## Порядок разработки

Изменения выполняются в отдельных Git-ветках и попадают в `main` через pull request после тестирования.
