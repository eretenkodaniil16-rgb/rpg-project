# Pilot texture slots

Каждый PNG имеет размер `16×16`, использует жёсткую пиксельную сетку и
подключается к одноимённому material slot:

- `skin.png`;
- `hair.png`;
- `scarf.png`;
- `leather_dark.png`;
- `leather_mid.png`;
- `chainmail.png`;
- `silver.png`;
- `dark_steel.png`;
- `boots.png`.

Файлы можно редактировать независимо от модели. Имена и размер холста на
пилотном этапе менять нельзя. В Blender используется интерполяция `Closest`.

Это техническая стартовая раскладка, а не утверждённые финальные текстуры.
После проверки лица, силуэта, перспективы и сторон экипировки палитра и рисунок
материалов будут уточняться по одной группе за итерацию.
