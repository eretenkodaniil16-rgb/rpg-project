# HRA Heart model attribution

The anatomical heart meshes used by the Blender Frank–Starling / Anrep teaching scene are based on:

- **Human Reference Atlas 3D Reference Object Library — Heart, Male v1.2**
- Source: `https://ccf-ontology.hubmapconsortium.org/objects/v1.2/VH_M_Heart.glb`
- Human Reference Atlas: `https://humanatlas.io/3d-reference-library`
- License: **CC BY 4.0**
- Underlying anatomical provenance: **Visible Human Male**, U.S. National Library of Medicine.

Project modifications include Blender scene integration, material replacement, chamber-specific animation rigging, myocardial surface shading, camera/layout work, and procedural extensions for the great-vessel tree.

The original HRA GLB binary is downloaded during CI rendering and is not vendored in this repository.
