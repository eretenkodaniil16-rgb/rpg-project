# Blender: химическая синаптическая передача v01

Процедурная учебная 3D-анимация выделения нейромедиатора в химическом синапсе. Сцена строится из Python в Blender 5.2 LTS и рассчитана на итоговое видео **45 секунд, 30 FPS, 1350 кадров**.

## Что визуализируется

1. Состояние покоя — синаптические везикулы и закрытые потенциалзависимые Ca²⁺-каналы.
2. Приход потенциала действия к пресинаптической терминали.
3. Открытие Ca²⁺-каналов и вход Ca²⁺.
4. Перемещение подготовленной везикулы к активной зоне, докинг и слияние.
5. Формирование поры слияния и экзоцитоз кванта нейромедиатора.
6. Диффузия медиатора через синаптическую щель и связывание с рецепторами.
7. Ионотропный ответ и отдельная метаботропная ветвь со вторичными посредниками.
8. Прекращение действия медиатора: обратный захват, ферментативное удаление и диффузия.
9. Восстановление исходного состояния.

## Временная шкала

- 00–04 с — покой;
- 04–08 с — потенциал действия;
- 08–13 с — вход Ca²⁺;
- 13–19 с — докинг/слияние везикулы;
- 19–24 с — экзоцитоз;
- 24–31 с — диффузия и связывание;
- 31–36 с — постсинаптический ответ;
- 36–41 с — удаление медиатора;
- 41–45 с — восстановление.

## Научная подача

Сцена является учебной схемой, а не пространственно масштабной реконструкцией: ширина синаптической щели, размеры ионов, молекул, каналов и везикул намеренно увеличены для читаемости. Визуальная последовательность следует общему механизму химической синаптической передачи.

Пользователь указал два основных учебных источника для финальных текстовых формулировок: учебник под редакцией Покровского и Guyton & Hall. В v01 титры сформулированы как краткие нейтральные физиологические подписи. Перед финальной версией текста их следует сверить с конкретными страницами/изданием, которые будут предоставлены пользователем; дословные цитаты в текущей версии не используются.

## Состав

- `synapse_data.py` — 45-секундный таймлайн и фазовые подписи;
- `blender_helpers.py` — геометрические, анимационные и текстовые примитивы;
- `synapse_scene_v01.py` — анатомическая сцена, рецепторы, везикулы, Ca²⁺ и медиатор;
- `render_synapse_v01.py` — сборка сцены, PNG-рендер, `.blend` и manifest;
- `test_synapse_data.py` — тест таймлайна;
- `test_synapse_source_contract.py` — статическая проверка Blender-сценариев.

## Локальная сборка

```powershell
blender.exe --background --factory-startup --python-exit-code 1 `
  --python tools/blender_synapse_animation/render_synapse_v01.py -- `
  --output-root artifacts/synapse_v01 `
  --frame-start 1 --frame-end 1350 `
  --resolution 1080 --render-samples 64 --save-blend
```

Для быстрого просмотра можно использовать `--resolution 540` и один/несколько отдельных диапазонов кадров.

## Итоговый контракт

Финальный CI-пайплайн должен собрать нативную PNG-последовательность 1920×1080, 30 FPS, 1350 кадров и затем закодировать два MP4: master с повышенным качеством и совместимую H.264-версию для телефона/браузера. `.blend`, manifest и постер сохраняются вместе с видео.
